Ética, Discriminação Algorítmica e LGPD

Considerações éticas

A utilização de algoritmos de Machine Learning na análise de crédito pode melhorar a eficiência das decisões financeiras, mas também apresenta riscos de discriminação algorítmica.

No modelo desenvolvido, características como idade, renda mensal, tempo de emprego e score de crédito podem refletir desigualdades socioeconômicas existentes. Consequentemente, determinados grupos podem apresentar taxas de recusa maiores, mesmo quando não existe intenção explícita de discriminá-los.

Atributos sensíveis, como raça, religião, informações de saúde e orientação sexual, não devem ser utilizados indiscriminadamente para decisões de crédito, ainda que possam aumentar o desempenho estatístico do modelo. A exclusão desses atributos, entretanto, não garante a ausência de discriminação, pois outras variáveis podem funcionar como indicadores indiretos.

Em relação à Lei Geral de Proteção de Dados (LGPD), uma aplicação real deve estabelecer uma base legal adequada para o tratamento dos dados pessoais, respeitar os princípios de finalidade, necessidade, transparência e segurança e adotar medidas para prevenir acessos não autorizados. Também deve observar os direitos dos titulares, incluindo as disposições aplicáveis à revisão de decisões tomadas unicamente com base em tratamento automatizado de dados pessoais.

Por fim, o modelo desenvolvido utiliza dados sintéticos e possui finalidade educacional. Sua aplicação em instituições financeiras reais exigiria validações adicionais, monitoramento de vieses, mecanismos de contestação e medidas de governança para assegurar decisões responsáveis.
